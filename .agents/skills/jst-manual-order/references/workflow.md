## 连接、导航与速度

Playwright `chromium.connectOverCDP('http://127.0.0.1:9224')`；选 URL 为 `https://w.erp321.com/epaas` 的页。`browser.close()` 对 CDP 连接用于断开，保持用户浏览器运行；不要调用 context.close() 或杀进程。

主页面内有多个 iframe：
- 首页 URL 含 `#/erp-home`，点击精确文字“订单”。
- 订单列表 URL 含 `/app/order/order/list.aspx`；先“新增/拉取订单”再“手工下单”。
- 新单 URL 含 `newOrder.aspx`。
- 店铺选择器 URL 含 `DataSourcePicker.aspx?type=shop`。
- 商品选择器 URL 含 `itemskudialogNew.aspx`。
- 查询侧栏 URL 含 `/app/order/filter/filter.aspx`。

点击后等待目标 frame 导航到实际 URL，不能仅等 frameattached。DOM 中可能有不可见预加载 iframe。定位目标 frame 及可见候选，店铺同名可能同时出现在最近使用与总列表。合理设置短超时，变更页面结构才重新读取局部 DOM；同一阶段的字段批量填写，避免每个字段一个工具调用或重复全页扫描。不要在未授权时创建订单作测试。

## 商品选择

推荐通过“添加新的商品”打开选择器，精确查询 SKU，读标签和规格再加入。选择器“清空”可清除旧筛选，然后填该 frame 的 #sku_id，点击“搜索”，等精确 SKU 出现。

双击结果 SKU 可加入并关闭选择器；回新单等待 #iq<SKU> 出现，填写数量并 Tab 触发更新。单个装数量就是个数；多件装数量是包数。一次添加一个目标，不重新模糊检索已知SKU。

备用快速方式：新单中的 #sku_id 填写并 Enter，会出现带 `input.qty` 的候选表格。仅点击商品名不会加入；找到含该商品的 tr，填其 input.qty，按 Enter，然后等 #iq<SKU> 出现。这个快捷方式不显示停售标签，应先核实目标 SKU 状态。

## 保存与核验

明确授权且表单复核一致后，点击精确“确定”（不是“确定并继续”）。若出现必填/校验错误，修正后再提交。服务器可能自动执行既有赠品/分仓/筛选规则，不修改全局规则以便于本次操作。

成功后新单 frame 消失。订单列表含新内部单号、买家和数量；查询侧栏 #o_id 输入内部单号并 Enter 可定位，等待更新后读买家、店铺、数量及状态。只点击单号可能仅选中单元格，不能据此宣称打开了详情。

首次接入新账号时先询问标签偏好（不加标签，或指定标签名称），后续沿用该账号确认的规则。若需标签，定位并只选中本次新建订单，在“标记/多标签”处追加指定标签并保存，保留其他标签。以实际可见控件核对操作路径，不猜测未验证的标签选择器或接口。系统若已自动加上所需标签，回读确认即可，不重复写入。核验内部单号、订单状态及约定标签后再交付；标签失败时明确说明建单已成功而标签未完成，不重新建单。

已验证的详情入口：在列表中 hover 指定内部单号所在单元格，点击其 `[title="查看订单详情"]`，等待 `OrderEditorNew.aspx`。标签可在该详情的“添加标签”进入：等待 `OrderLabelPicker.aspx`，按用户指定名称找到对应复选框，勾选后在 `epaas-dialog-frame.html` 的“确定”保存。已有标签要保留。回读详情中的 `.label_item` 及“添加标签”日志；不要仅用全页精确文本匹配，因为标签与日志可能同名。至少一次重新打开该订单确认标签及备注确实保存。

网络失败或保存结果不明时先按买家/时间查重，不盲目重复点保存。最终仅报告已验证的信息；没有内部单号不得说建单成功。
